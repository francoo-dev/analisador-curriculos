# Analisador de Currículos

Projeto pessoal em desenvolvimento que compara um currículo com uma
vaga de emprego e apresenta sugestões para adequá-lo aos requisitos
da oportunidade.

A ideia surgiu de uma dificuldade pessoal: montar um currículo para
vagas de estágio e identificar quais qualificações destacar.

## Objetivo

Ajudar o usuário a identificar requisitos da vaga, comparar essas
informações com seu currículo e receber sugestões para apresentá-lo
de forma mais adequada, sem inventar habilidades ou experiências.

## Tecnologias

- HTML, CSS e JavaScript para a interface.
- Python para o processamento.
- Ollama para executar o modelo de inteligência artificial localmente.

## Status

Esta é uma primeira versão e o projeto ainda está em desenvolvimento.
As funcionalidades precisam de mais testes e melhorias.

## Próximos passos

- Melhorar a análise dos requisitos técnicos das vagas.
- Apresentar a comparação entre o currículo e a vaga com mais clareza.
- Aperfeiçoar a experiência de uso.
- Revisar o desempenho e a confiabilidade das sugestões.
